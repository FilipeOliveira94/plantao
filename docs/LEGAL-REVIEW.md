# Legal and regulatory review (Brazil)

Review for issue [P0-03](https://github.com/FilipeOliveira94/plantao/issues/105), done on 2026-11-28, before the MVP goes public ([P0-04](https://github.com/FilipeOliveira94/plantao/issues/106)).

> **This is not legal advice.** An AI agent wrote this review from the primary texts linked in each row, on the date above. It is a map of the rules and of what the project does about each one, not a lawyer's opinion, and it does not replace one. Rows marked **⚖** need a lawyer's opinion; the column says before which step. Laws change: a row is only as current as its review date.

How to read the tables: **Applies?** says whether the rule binds the project as it is today (`yes`, `no`, `partly`, `unclear`, or `later` for a planned feature). **Action** is `none`, `change` (an existing issue that changes the game) or `new issue`. Quotes are short excerpts of the official text, in Portuguese.

## Facts the review assumes

Every conclusion below depends on these facts. If one changes, re-check the rows that cite it ([Re-check triggers](#re-check-triggers)).

- **Publisher.** Filipe publishes the MVP as a private individual (pessoa física): no company, no revenue, no ads, no analytics, no paid features. A company may come later if the use case is proven.
- **Physicians named.** Nobody named in the game or the repo holds a CRM today. Later releases may name the physicians who review cases ([`REVIEW-STATUS.md`](REVIEW-STATUS.md)).
- **Audience.** Physicians and medical students working in Brazil. The game is open to anyone with a browser: no sign-in, no age check.
- **Hosting.** A static site on GitHub Pages (P0-04). GitHub serves the files and keeps its own access logs under its own terms. The game has no server of its own.
- **Data.** The save (XP, case results, settings, tutorial state) stays in the browser's `localStorage` ([`src/game/progress.js`](../src/game/progress.js)). The save schema has a `doctorName` field, but no screen sets it today. Export and import produce a local file or code that the player copies. The game sends no data anywhere. The "Relatar um problema neste caso" link opens a prefilled public GitHub issue that the player submits on GitHub with their own account. The screen says so.
- **Content.** 23 fictional cases written by AI from published guidelines, cited in [`REFERENCES.md`](REFERENCES.md) and still pending physician review. Drug names are generic: a spot check found only "AAS", the DCB abbreviation for acetylsalicylic acid. The queue uses five priority colors, their labels and target times (`TRIAGE` in `src/data/catalog.js`) and names Manchester twice in player text. No flowcharts or discriminators are reproduced.
- **Places.** Five units in real cities with invented names, three of which use real neighborhoods ([P4-06](https://github.com/FilipeOliveira94/plantao/issues/75)).
- **Assets.** No third-party assets: the scene is drawn in code and the sound and music are synthesized ([`CREDITS.md`](../CREDITS.md)). The code and content are under a view-only license ([`LICENSE`](../LICENSE)).
